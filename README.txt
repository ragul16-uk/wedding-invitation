# S Sivapragasam & K Jeniliya — E-Invitation

## Run
1. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.
2. Open `index.html` in Chrome/Edge.
3. The invitation is responsive for mobile and desktop.

## Music
Put your MP3 file here:
`assets/music.mp3`

Then tap the music button in the bottom-right corner.

## Customize
- Couple photo: `assets/couple.jpeg`
- Main content: `index.html`
- Colours/layout: `style.css`
- Interactions: `script.js`
